# Axcentra End-to-End Sales Analysis

## Project Overview
This project analyzes sales data to identify business trends, product performance, country-wise sales, and segment-wise profitability.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib)
- Jupyter Notebook
- SQL
- Microsoft Excel
- Power BI Desktop

## Project Workflow
1. Cleaned and explored the dataset using Python.
2. Analyzed sales, profit, products, countries, and business segments using SQL and Python.
3. Used Excel for data analysis and visualization.
4. Created an interactive Power BI dashboard with KPI cards, charts, and slicers.

## Key Metrics
- Total Sales: approximately 118.73 million
- Total Profit: approximately 16.89 million
- Total Units Sold: approximately 1.13 million
- Overall Profit Margin: approximately 14.23%

## Dashboard Features
- Total Sales, Total Profit, Units Sold, and Profit Margin KPI cards
- Monthly Sales Trend
- Country-wise Sales
- Product-wise Sales vs Profit
- Segment-wise Sales vs Profit
- Filters for Year, Country, Product, and Segment

## Project Files
This repository contains the project dataset, cleaned data, Python notebook, SQL queries, Excel workbook, and Power BI dashboard.

## Conclusion
The analysis provides an overview of sales performance and profitability across products, countries, and business segments, supporting data-driven business decisions.
